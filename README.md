# CHEN212 Mission 01 — From Lab Bench to Chemical Plant

A mobile-friendly Streamlit activity for CHEN212.

## Local run
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deploy on Streamlit Community Cloud
1. Create a GitHub repository.
2. Upload `app.py` and `requirements.txt`.
3. Go to Streamlit Community Cloud and create a new app from that repository.
4. Set the main file path to `app.py`.
5. Deploy.
6. Open the public app URL on a phone.
7. Generate a QR code pointing to the public URL and place it on the lecture slide.

## Notes
- Students do not need GitHub or Streamlit accounts to use the public app.
- The activity is designed for 3–4 students and includes individual work followed by an in-class team briefing.
- The built-in score is formative, not intended as a formal grade.
