# Engineering Crisis Game - Public Host Enabled

Use the public Streamlit URL in two ways:

- Student game: `https://YOUR-APP.streamlit.app/?view=play`
- Host leaderboard: `https://YOUR-APP.streamlit.app/?view=host`

Important: Do not run the host screen locally during the event. Open the public Streamlit host URL on your laptop, and let students scan/play from the same public app.

Install/run locally:

```bash
pip install -r requirements.txt
streamlit run app.py
```
