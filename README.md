# Can You Think Like an Engineer?

## Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Public deployment
Deploy on Streamlit Cloud. Use:

- Player link: `https://YOUR_APP.streamlit.app/?view=play`
- Host/control link: `https://YOUR_APP.streamlit.app/?view=host`

The host screen includes the QR code, live leaderboard, reset button, answer key, and play-mode link.
